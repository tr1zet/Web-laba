# Лабораторная работа №2 — jQuery Portfolio

Продолжение сайта-визитки из лабораторной работы №1.

## Реализовано

- jQuery 3.7.1;
- мобильное выпадающее меню;
- плавная навигация по разделам;
- подсветка активного пункта меню при скролле;
- динамическая загрузка проектов из `data/portfolio.json` через AJAX;
- карусель проектов с кнопками, точками, автопрокруткой и свайпом на телефоне;
- модальное окно проекта;
- интерактивный блок навыков с круговой диаграммой;
- AJAX-симуляция отправки формы;
- валидация формы;
- всплывающее уведомление после отправки;
- кнопка «Вверх» с плавной прокруткой;
- адаптивная верстка для ПК, планшета и телефона.

## Запуск

Открой папку в VS Code и запусти `index.html` через Live Server. Это нужно для корректной работы AJAX-запроса к JSON.

## О проекте
Портфолио продолжает лабораторные работы №1–2. Внешний вид и функциональность сайта сохранены, а стили полностью переработаны на Sass/SCSS.

В проекте используются:
- модульная структура Sass с `@use` и `@forward`;
- переменные, карты, функция `rem()` и миксины;
- БЭМ-именование классов;
- светлая и тёмная темы;
- сохранение темы в `localStorage`;
- jQuery, AJAX, валидация формы;
- динамическая загрузка проектов из JSON;
- карусель проектов, кнопки, точки и свайп на телефоне;
- модальное окно, toast-уведомление, плавная навигация и кнопка «Наверх».

## Запуск с нуля
Требуется Node.js LTS и npm.

```bash
npm install
npm run build
```

После сборки запустите проект через Live Server в VS Code или другой локальный HTTP-сервер. AJAX-запросы к JSON не рассчитаны на открытие `index.html` напрямую через `file://`.

Для разработки Sass:
```bash
npm run sass:dev
```

Команда `npm run sass:dev` следит за `scss/main.scss` и автоматически пересобирает `dist/css/main.css`.
